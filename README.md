# Centro de Prensa — MIDES Florida

Plataforma institucional de prensa para MIDES Florida.

## Objetivo

Centralizar comunicados, fotografías, videos y documentos para facilitar el trabajo de los medios de comunicación del departamento.

## Primera versión

- Sala de prensa pública.
- Buscador de contenidos.
- Ficha de comunicado.
- Panel editorial inicial.
- Diseño responsive y accesible.
- Identidad basada en la marca oficial del Ministerio de Desarrollo Social.
- Arquitectura preparada para conectar Google Sheets, Google Drive y un servicio de mailing.

## Identidad institucional

La interfaz utiliza la marca oficial del MIDES y toma como referencia el Manual de Identidad Visual publicado por el Ministerio.

Fuente oficial: https://www.gub.uy/ministerio-desarrollo-social/comunicacion/publicaciones/manual-identidad-visual-del-ministerio

## Integración editorial actual

- Google Sheets como fuente central de comunicados.
- Google Apps Script como API web.
- Panel editorial conectado para crear, editar, publicar, despublicar y eliminar.
- Sala pública conectada para mostrar únicamente contenidos publicados.
- Detalle individual de cada comunicado conectado a la API.
- Guía de instalación en `apps-script/SETUP.md`.
